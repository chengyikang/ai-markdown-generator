# ai-markdown-generator

Next.js 项目，使用 TypeScript、App Router 与 Tailwind CSS。

## 开发

```bash
npm install
npm run dev
```

在浏览器中打开 [http://localhost:3000](http://localhost:3000)。

## 脚本

- `npm run dev` — 启动开发服务器（Turbopack）
- `npm run build` — 生产构建
- `npm run start` — 启动生产服务器
- `npm run lint` — 运行 ESLint
